GLOSARIO · PARTE 1
Palabras que
necesitas conocer
Si nunca has usado herramientas técnicas, esta página es para ti. Aquí explicamos todos los términos que aparecen en esta guía, con ejemplos del día a día.
NODE.JS
Node.js es un programa gratuito que tienes que instalar en tu ordenador. No lo verás ni lo usarás directamente — trabaja en segundo plano y es lo que hace funcionar el dashboard. Piénsalo como el motor de un coche: no lo ves, pero sin él el coche no arranca.
→ Se instala desde una página web (nodejs.org), igual que instalas cualquier aplicación. Solo tienes que hacer clic en "Siguiente" varias veces.
API KEY / API TOKEN
Una API key (también llamada token o clave de API) es una contraseña especial de un solo uso que te da un servicio para que otras aplicaciones puedan conectarse a él en tu nombre. Es como la llave de tu casa: solo tú la tienes, y solo con ella se puede abrir la puerta.
→ Cuando Apify te da un token, básicamente te está diciendo: "Aquí tienes tu llave. Dásela al dashboard para que pueda leer tus datos de TikTok." Sin esa llave, el dashboard no puede acceder a nada.
SYNC / SINCRONIZAR
Sincronizar significa "traer los datos más recientes de internet a tu dashboard". Es como actualizar el correo: pulsas un botón y el dashboard va a buscar todos tus nuevos vídeos, likes y seguidores.
→ Solo necesitas hacerlo una vez a la semana. Los datos se guardan en tu ordenador y siguen ahí aunque cierres el dashboard.
SCRAPING
Scraping es el proceso de leer automáticamente la información pública de una página web. El dashboard usa scraping para leer las estadísticas de tus perfiles de TikTok e Instagram — exactamente la misma información que ve cualquier persona al visitar tu perfil.
→ Es completamente legal y seguro. No accede a datos privados ni necesita tu contraseña de TikTok o Instagram.
LOCALHOST
Localhost es la dirección de "tu propio ordenador" dentro del navegador. Cuando el dashboard está funcionando, se abre en la dirección localhost:3000 — eso significa que la página web del dashboard está corriendo en tu propio ordenador, no en internet.
→ Nadie más puede ver tu dashboard. Solo tú, en tu ordenador, puedes acceder a él.

GLOSARIO · PARTE 2
Más términos
explicados
ENGAGEMENT
El engagement es el porcentaje de personas que interactúan con tu contenido (likes, comentarios, shares, guardados) respecto al total que lo vio. Un engagement alto significa que tu contenido conecta con la gente — es más importante que los views.
→ Si un vídeo tiene 1.000 views y 70 likes, su engagement es del 7%. Por encima del 5% se considera muy bueno en TikTok.
HOOK
El hook son los primeros 2-3 segundos de tu vídeo. Es lo más importante de cualquier contenido en redes sociales — si el hook no engancha, la gente hace scroll y no ve el resto. El dashboard analiza qué tipo de hooks funcionan mejor en tu cuenta.
→ Un buen hook puede ser una pregunta que choca ("¿Por qué el 90% de creadores fracasa?"), un dato sorprendente, o mostrar el resultado final antes de explicar el proceso.
MODELO DE IA
Un modelo de IA es la "versión" concreta de inteligencia artificial que usas. Claude Sonnet, GPT-4o y Gemini Flash son modelos distintos, cada uno con sus características. En el dashboard puedes elegir qué modelo usar — los más avanzados generan mejores resultados pero cuestan un poco más por uso.
→ Es como elegir entre un coche básico y uno de gama alta. Ambos llevan al mismo sitio, pero el premium es más rápido y cómodo.
CACHÉ
La caché es una copia de los datos que se guarda en tu ordenador para no tener que descargarlos de nuevo cada vez. El dashboard guarda tu último sync en caché — por eso cuando abres el dashboard ya tienes los datos sin necesidad de sincronizar de nuevo.
→ Si limpias la caché del navegador, perderías los datos guardados. Por eso no recomendamos limpiarla.
PROVEEDOR DE IA
Un proveedor de IA es la empresa que ofrece el servicio de inteligencia artificial. El dashboard es compatible con tres: Anthropic (hace Claude), OpenAI (hace ChatGPT) y Google (hace Gemini). Tú eliges cuál usar según la que ya tengas o prefieras.
HANDLE
El handle es tu nombre de usuario en una red social, con el símbolo @ delante. Por ejemplo: @tucuenta. El dashboard necesita tu handle para saber de qué cuenta tiene que traer los datos.

01 · REQUISITOS PREVIOS
Antes de empezar
Solo necesitas instalar una cosa: Node.js. El resto lo hace el dashboard automáticamente.

¿QUÉ ES NODE.JS Y CÓMO SE INSTALA?

Node.js es una aplicación gratuita que se instala en tu ordenador como cualquier otro programa — desde una página web, sin tocar el terminal. Una vez instalado, no tienes que hacer nada más con él: trabaja en segundo plano y el dashboard lo usa automáticamente.

  • 1
    Abre nodejs.org en tu navegador
    Ve a nodejs.org. Verás un botón verde grande con las letras LTS. Ese es el que necesitas — LTS significa "versión estable y recomendada".
  • 2
    Descarga e instala
    Pulsa el botón verde para descargar. Cuando termine, abre el archivo descargado y sigue el proceso de instalación: "Siguiente → Siguiente → Instalar". Es exactamente igual que instalar cualquier otra aplicación.
  • 3
    Listo — no necesitas hacer nada más
    Node.js queda instalado en tu ordenador. No abre ninguna ventana ni aparece en el escritorio. Simplemente está ahí, listo para cuando el dashboard lo necesite.
💡 EL SCRIPT TE AVISA AUTOMÁTICAMENTESi intentas abrir el dashboard sin tener Node.js instalado, el script te mostrará un mensaje claro y abrirá nodejs.org en tu navegador. No tienes que preocuparte de verificarlo tú.
02 · ARRANCAR EL DASHBOARD
Primer arranque
  • 1
    Descomprime el ZIP y guarda la carpeta
    Doble clic en el ZIP descargado. Se crea una carpeta llamada dashboard. Guárdala donde quieras — Escritorio, Documentos, etc. No la muevas después.
  • 2
    Abre el dashboard con doble clic
    Mac: doble clic en iniciar.command
    Windows: doble clic en iniciar.bat

    La primera vez instala dependencias automáticamente (~30 segundos). El navegador se abre solo en localhost:3000.
  • 3
    Introduce tus credenciales de acceso
    Verás una pantalla de login. Introduce:

04 · CONECTAR TUS REDES SOCIALES
Configurar Apify
Apify es un servicio web que extrae los datos públicos de tus cuentas de TikTok e Instagram. Tiene un plan gratuito con $5 de crédito al mes — más que suficiente para usar el dashboard sin coste.
  • 1
    Crea tu cuenta gratuita
    Ve a apify.com → pulsa "Sign up" → regístrate con tu email. No necesitas tarjeta de crédito para el plan gratuito.
  • 2
    Consigue tu API Token
    Dentro de Apify: menú lateral → Settings → Integrations → copia el Personal API token.

    ¿Qué es este token? Es la "llave" que le das al dashboard para que pueda leer tus datos de Apify. Es una cadena de letras y números que empieza por apify_api_.
  • 3
    Pégalo en el dashboard
    En el dashboard: CONFIGURAR → sección APIFY → pega el token → pon tus handles con el @ delante (@tucuenta) → PROBAR CONEXIÓN (debe salir verde) → GUARDAR.
ℹ ¿LOS DATOS SON SEGUROS?Sí. Apify solo lee información pública — exactamente lo que ve cualquier persona al visitar tu perfil. No accede a mensajes, datos privados ni necesita tu contraseña de TikTok o Instagram.

06 · PRIMER SYNC
Traer tus datos
reales
Una vez configurado Apify y tus handles, estás listo para traer tus datos reales de TikTok e Instagram.
  • 1
    Pulsa ↻ SYNC en la barra superior derecha
    El botón está en la parte superior del dashboard, junto al reloj. Al pulsarlo se abre una pantalla de progreso.
  • 2
    Espera 2-5 minutos
    Apify tarda entre 2 y 5 minutos en extraer todos los datos. Verás mensajes de progreso: "Scrapeando TikTok... Scrapeando Instagram... Procesando datos..." No cierres el navegador durante este proceso.
  • 3
    El badge cambia a DATOS REALES
    Cuando termina, el indicador en la barra superior cambia de DEMO DATA (en naranja) a DATOS REALES (en verde). A partir de aquí todas las métricas e ideas se basan en tu contenido real.
✓ ENHORABUENA — CONFIGURACIÓN COMPLETASi llegaste aquí con todo en verde, tu dashboard está 100% configurado. El siguiente sync lo puedes hacer cuando quieras — una vez por semana es más que suficiente.
ℹ LOS DATOS SE GUARDAN AUTOMÁTICAMENTEDespués del sync, los datos se guardan en tu ordenador. Si cierras el dashboard y lo vuelves a abrir mañana, los datos siguen ahí — no necesitas hacer sync de nuevo.
💡 ¿CUÁNDO HACER SYNC?Recomendamos una vez a la semana, los lunes antes de planificar el contenido. Así siempre trabajas con datos frescos sin gastar crédito de Apify innecesariamente.

09 · ERRORES FRECUENTES
Algo no funciona —
soluciones rápidas
Si tienes un problema, lo más probable es que esté aquí. Lee el error que ves en pantalla y busca el que más se parece.
✕ El dashboard no se abre / el navegador no aparece
La ventana negra se cerró o Node.js no está instalado.
1. Comprueba que la ventana negra sigue abierta — si se cerró, vuelve a hacer doble clic en el script de arranque
2. Si aparece "node no se reconoce como comando", instala Node.js desde nodejs.org
3. Abre el navegador manualmente y escribe localhost:3000
✕ Mac: "No se puede abrir porque es de un desarrollador no identificado"
macOS bloquea archivos descargados de internet por seguridad. Es normal.
Clic derecho sobre iniciar.command → "Abrir" → en el aviso pulsa "Abrir". Solo pasa la primera vez.
✕ SYNC falla o se queda cargando sin terminar
Token de Apify incorrecto, sin crédito, o handle mal escrito.
1. CONFIGURAR → APIFY → PROBAR CONEXIÓN
2. Si falla: copia el token de nuevo desde apify.com (Settings → Integrations)
3. Asegúrate que el handle tiene el @: @tucuenta
4. Verifica en apify.com que tienes saldo (mínimo $0,10)
✕ La IA no genera — "Sin API key" o error de conexión
La API key no está guardada, es incorrecta, o no pulsaste GUARDAR.
1. CONFIGURAR → IA GENERATIVA → selecciona tu proveedor
2. Pega la API key completa, sin espacios al inicio ni al final
3. Pulsa PROBAR CONEXIÓN → debe salir verde
4. Pulsa GUARDAR — este paso es obligatorio
✕ Los datos han desaparecido al reabrir el dashboard
Limpiaste el caché del navegador o estás usando un navegador diferente.
1. Usa siempre el mismo navegador (Chrome o Safari recomendado)
2. No limpies el caché del navegador
3. Si los perdiste: simplemente haz ↻ SYNC de nuevo — los datos vuelven en 2-5 min
✕ Las API keys desaparecen al reiniciar
No se pulsó GUARDAR después de configurar.
Vuelve a CONFIGURAR, introduce las keys y pulsa GUARDAR. A partir de ahí persisten indefinidamente.

PREGUNTAS FRECUENTES

¿Tengo que pagar algo más?
Las APIs de IA cuestan ~€0,01 por generación. Apify tiene $5/mes gratis. Con uso normal el coste mensual es prácticamente cero.

¿Funciona sin internet?
El dashboard abre sin internet. Solo necesitas conexión cuando haces SYNC o generas ideas con IA.

¿Puedo usarlo en más de un ordenador?
Sí. Copia la carpeta a otro ordenador y sigue el mismo proceso de arranque.

¿Es seguro pegar mis API keys?
Sí. Todo corre en tu ordenador. Las API keys nunca salen de tu máquina.

¿Puedo gestionar cuentas de clientes?
Sí. Cambia los handles en CONFIGURAR cuando quieras analizar otra cuenta.

¿Recibiré actualizaciones?
Sí, por email con un nuevo ZIP. Tu configuración se restaura automáticamente.
